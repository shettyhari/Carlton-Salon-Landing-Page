# Carlton Wellness Salon: Franchise Landing Page

Landing page for the Carlton Wellness Salon franchise, with a lead form that saves enquiries to a database.

## Project structure

```
carlton-landingPage/
├── frontend/           Landing page and thank-you page (static HTML, CSS, images)
├── backend/            Lead API (Node.js + Express) that validates and saves form submissions
├── database/           Table setup: Knex migrations + plain SQL for MySQL, PostgreSQL, SQLite
├── deploy/             Build script, PM2 process file, Nginx example, deployment guide
├── release/            Ready-to-upload copies, generated by `npm run build`
│   ├── backend/
│   └── frontend/
├── .gitignore
├── package.json        Root scripts (dev, build, test, migrate)
└── README.md
```

## Run locally

Requires Node.js 18 or newer.

```bash
npm run install:backend
npm run dev
```

Open http://localhost:4000. The backend serves the landing page and saves leads to a local SQLite file (`backend/data/leads.sqlite`), so no database server is needed for testing.

## How the lead form works

1. A visitor fills in the form in the hero section of `frontend/index.html`.
2. The page sends the details to `POST /api/leads`.
3. The backend checks the name, phone and email, filters spam (hidden honeypot field, max 10 submissions per IP per 10 minutes) and saves the lead to the `leads` table.
4. The visitor is taken to `thank-you.html`.

Other endpoints: `GET /api/health` reports whether the database is reachable.

## Configuration

Copy `backend/.env.example` to `backend/.env` and edit it. Key settings:

| Setting | Purpose |
|---|---|
| `DB_CLIENT` | `sqlite` (default), `mysql` or `postgres`. The database is still to be decided |
| `DATABASE_URL` or `DB_HOST` / `DB_USER` / `DB_PASSWORD` / `DB_NAME` | Database login for MySQL or PostgreSQL |
| `SERVE_FRONTEND` | `true` to serve the page from the backend, `false` when Nginx or cPanel serves it |
| `CORS_ORIGINS` | Only if the page and API are on different domains |

See `database/README.md` for database options.

## Scripts (from the repo root)

| Command | What it does |
|---|---|
| `npm run install:backend` | Installs backend dependencies |
| `npm run dev` | Runs the backend with auto-reload on http://localhost:4000 |
| `npm start` | Runs the backend |
| `npm test` | Runs the backend API tests |
| `npm run migrate` | Creates or updates the `leads` table |
| `npm run build` | Refreshes `release/frontend` and `release/backend` |
